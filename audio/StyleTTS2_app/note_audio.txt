More like reference voice (stable narrator):

alpha=0.1–0.3, beta=0.3–0.6

More expressive / acted:

alpha=0.3–0.6, beta=0.7–1.0



10) For characters + styles: what’s the best workflow?

For audiobooks, the most robust approach is:

Keep one neutral reference per character:

Sas_neutral.wav, Max_neutral.wav

Keep extra reference clips per emotion if you want:

Max_angry.wav, Max_sad.wav

For each dialogue line:

pick character ref

set beta higher for emotional lines

optionally switch to emotional ref clip

This gives you control without needing to label everything during training.



8) How many audio+text pairs do I need?

There’s no single “magic number”, but here’s a realistic guide:

Minimal test (“does it work at all?”)

50–200 clips (~5–20 minutes)
This is like the finetune demo scale.

Useful single-voice quality

500–2000 clips (~1–3 hours) of clean voice

consistent mic, low noise

Strong emotional range (angry/sad/happy etc.)

Prefer separate style sets, e.g.:

30–60 minutes per style

Or at least a few hundred lines per emotion if you want reliable control.

If you only want zero-shot + a slight accent shift, you need less.
If you want the model to “be Sas” by default without reference, you need more.
